# Prostapaper Hackathon Submission

ProstaPaper converts prostate pathology reports and hand-drawn sector diagrams into structured, human-reviewed records for REDCap.

This repository contains the source-code artifact for the Rakathon 2026 submission.

## Contents

- `apps/`: web application, API, document ingestion and case mapping.
- `packages/`: shared contracts, database schema and migrations, extraction, mapping and development tooling.
- `docs/`: architecture, design notes, clinical workflow documentation and references.
- `tools/`: REDCap tooling source.
